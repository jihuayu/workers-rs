# Plan: RPC class instances

## 背景

`workers-rs` README 已将“Class instances”列为 RPC 未完整支持项。

## 目标

支持 RPC 中的类实例语义，包括实例创建、方法调用和生命周期管理。

## 设计

1. 引入实例句柄机制：远端实例映射为本地可持有的 handle。
2. client stub 保存 handle 与类型信息，方法调用时携带实例上下文。
3. 增加显式释放或自动回收机制，避免远端实例泄漏。
4. 保持 FFI 层薄封装，复杂语义放在 codegen 层。

## 需要做的工作

1. 定义实例句柄协议（标识、作用域、过期行为）。
2. 扩展 `worker-codegen` 生成：
3. 构造函数调用路径。
4. 实例方法调用路径。
5. `drop`/`dispose` 路径。
6. server 侧新增实例注册表与并发访问策略。
7. 测试：
8. 多实例并发调用。
9. 句柄失效和重复释放错误路径。
10. 文档补充“对象生命周期模型”。

## 风险与依赖

1. 实例生命周期管理不当会导致资源泄漏或悬垂句柄。
2. 并发与重试场景下句柄一致性需要明确保证。

## 验收标准

1. 能通过生成代码完成“创建实例->调用方法->释放实例”全流程。
2. 异常路径有明确错误语义。
3. 文档清楚说明实例生命周期和限制。
